# ADR-0003 风格 token 分两层

- 日期：2026-10-13
- 状态：已采纳
- 复查时间：M2 结束后

## 背景

用户提出"整体风格偏活力"。活力是主观偏好，且后续大概率还要调。

## 选项

- **A 直接改主色**：把原来的深蓝换成一套更亮的颜色。
- **B 基础 token + 可切换风格包**：结构与配色解耦，提供多套风格。

## 权衡

- A 改动最小，但以后每次调风格都要动组件样式，也没法做 A/B 对比。
- B 多一个文件，换来风格与结构解耦：三套并存、用户自选、新增风格只写变量。

## 决定

选 **B**。

- `design/tokens.css`：字号、间距、圆角、中性色——所有风格共用。
- `design/themes.css`：`[data-style]` 提供三套（活力 / 运动 / 霓虹），每套各有 `[data-theme="dark"]` 版本。
- 规则：**渐变只用于大面积色块**（顶栏、主按钮、选中胶囊、完成度环）；文字与描边一律用纯色 `--brand`，保证可读。
- 三套渐变的两个端点都刻意压深，确保白字可读。

## 后果

- 默认"活力"（靛蓝 → 亮蓝）；切换入口在应用「我的 → 外观」。
- 预览支持 `?style=neon&theme=dark`，方便截图与对比，且不写入设置。
