# ADR-0002 形态选 PWA

- 日期：2026-10-13
- 状态：已采纳
- 复查时间：需要系统级通知或应用商店分发时

## 背景

需求是"手机也能打卡"，同时要开源、零成本、单人维护。

## 选项

- **PWA**：网页应用 + Service Worker + 添加到主屏。
- **Capacitor 打包 APK**：真原生安装包，完整通知能力。
- **Electron / Tauri**：桌面为主，手机端弱。

## 权衡

| | 离线 | 通知 | 手机可用 | 打包 | 依赖 |
|---|---|---|---|---|---|
| PWA | 有（需 https） | 无主动推送 | 同代码直接用 | 零构建 | 零 |
| Capacitor | 原生 | 完整 | 需装包 | 需 JDK + Android SDK + Gradle（本机实测均无） | 数百 |
| Electron/Tauri | 桌面强 | 桌面可用 | 弱 | 分平台 | 重 |

## 决定

选 **PWA**。渐变只用于大面积色块的同类原则也适用于此：用最少的机制换取最大的可用面。通知能力让位给手机自带闹钟。

## 后果与已知限制

- 网页不能主动推送通知，提醒只显示时间 + 提示用户设系统闹钟。
- 局域网 http 下 Service Worker 不注册（浏览器要求安全上下文）；离线能力要部署到 https（GitHub Pages）才完整。
- 将来若要真 APK，套 Capacitor 即可，业务代码不用改。
