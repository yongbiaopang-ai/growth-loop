# Growth Loop · 前端设计规范 v1

> 配套设计稿：`design/mockup.html`（用 `python serve.py` 后在浏览器打开 `/design/mockup.html`）
> 设计 token：`design/tokens.css`（结构）+ `design/themes.css`（三套活力风格）。
> 预览与截图：`design/preview-four.html`（四页，中性模板）、`design/preview-app.html`（三套风格对照）。
> 本文件与设计稿一律使用通用示例数字，个人数字只写在 `seed.local.js`（已 gitignore）。

## 0. 设计目标

1. **30 秒能打完卡**：打开 → 点今天没做的那几项 → 关掉。主路径 ≤ 2 次点击完成一项。
2. **一屏一件事**：手机上一屏看到"今天要做什么、做到哪了"，不用滚动找信息。
3. **晚上用**：主场景是 18:00–23:00，深色模式是主场景之一，不是附加功能。
4. **状态要全**：不止画"全部完成"那条好看的路，断卡、未开始、空数据、离线都要有明确呈现。

非目标：不做社交、不做排行、不做动画炫技、不堆功能。任何增加打卡摩擦的设计一律否决。

## 1. 信息架构

四个 tab，职责互斥：

| Tab | 一句话职责 | 主要使用者动作 |
| --- | --- | --- |
| **今日** | 今天做什么、做到哪了 | 打卡（唯一高频动作） |
| **计划** | 这半年为什么这么练 | 阶段换了、迷茫时看一眼 |
| **趋势** | 半年到底有没有进步 | 每周/每月看一次 |
| **我的** | 基线与数据 | 第一次填基线，之后只导出备份 |

复盘（周日 21:15）不单独占 tab，从今日页的「周复盘」任务卡进入，写完回今日。

## 3. 关键组件

| 组件 | 用途 | 规则 |
| --- | --- | --- |
| 七天条带 | 本周 7 天一览 + 补打卡入口 | 点任意一天切到那天补卡；已打卡打点，漏卡显示橙色点 |
| 环形进度 | 今日/本周完成度 | 中心显示 `2/3`；完成度来自"已决定"的任务数（完成 + MVB + 跳过） |
| 阶段条 | 26 周所处位置 | 6 段对应 M1–M6，当前周高亮；检查点周加 ★ |
| 任务卡 | 打卡主单元 | 左侧 4px 色条 = 所属线；三态换底色：完成绿 / MVB 橙 / 跳过灰 |
| 主按钮 + 次按钮 | 完成 / 降级或跳过 | 「完成」一次点击；「降级 / 跳过」弹底部面板选 MVB 或跳过原因 |
| 热力格 | 26 周完成率 | 4 档颜色 + 未开始灰；不显示数字（移动端太挤） |
| 折线图 | 指标趋势 | 纯 SVG 手绘，不引图表库；必须有目标虚线 |
| 底部面板 | 选原因、写复盘 | 从底部升起，带遮罩；可点遮罩取消 |
| 提示条 | 规则提醒、离线提示 | 三种语义色：信息灰 / 提醒黄 / 警告红 |

## 4. 交互规则

**打卡**
- 点「完成」= 立即记下，按钮变成「✓ 已完成 20:05」+ 撤销入口。**不弹二次确认**。
- 点「降级 / 跳过」→ 底部面板：`降级为 MVB（写清 MVB 是什么）` / `加班` / `生病` / `临时有事` / `其他`。
- 再点一次已选中的状态 = 撤销（toggle 语义）。
- 跳过必须选原因，原因会显示在卡片上——这是为了月底复盘时能看出"卡在哪"。

**补打卡**
- 七天条带可点任意一天，进入那天的打卡界面，标题变成"补卡 · 10-22 周四"。
- 只允许补最近 7 天，更早的不给补（避免自我欺骗）。

**复盘**
- 周日 21:15 之后，今日页顶部出现「本周复盘待写」提示条。
- 复盘表单：四条线各一句 + 一句话总结；预填本周统计数字（已打卡天数、投入小时）作为参考。
- 保存后出现在趋势页的"周复盘记录"里。

**离线**
- 断网时照常可用，顶部细提示条告知"当前离线，打卡照常记"。
- 有变化才提示，不常驻。

## 5. 视觉规范

**颜色**：分两层。`design/tokens.css` 只管字号、间距、形状与中性色；`design/themes.css` 提供三套活力风格包，覆盖主色与状态色（见第 10 节）。

| 语义 | 取值来源 | 用例 |
| --- | --- | --- |
| 主色 | `--brand` 纯色 / `--brand-grad` 渐变 | 标题与描边用纯色；顶栏与主按钮用渐变 |
| 次要主色 | `--brand-2` | 渐变终点，图表第二色 |
| 品牌浅底 | `--brand-tint` / `--brand-line` | 标签、徽章、选中胶囊的底与描边 |
| 健身 / 英语 / 理财 / AI | `--fitness` `--english` `--finance` `--ai` | 任务色条与圆点，四线恒定区分 |
| 完成 | `--ok` / `--ok-tint` | 已完成态 |
| MVB | `--mvb` / `--mvb-tint` | 降级态 |
| 跳过 | `--skip` / `--skip-bg` | 跳过态 |
| 警告 | `--warn` / `--warn-tint` | 断卡、减量周 |
| 危险 | `--danger` | 清空数据 |
| 辉光 | `--glow` | 主按钮与顶栏的彩色投影，活力的主要来源 |

**字号**：标题 18 / 卡片标题 15 / 正文 14 / 辅助 12 / 标签 11（最小 11px，不再小）

**间距**：4 的倍数；卡片内边距 14，卡片间距 10，屏幕内边距 12

**形状**：卡片圆角 14、按钮 10、胶囊 999、阴影极轻（主要靠 1px 描边区分层次）

**触控**：任何可点区域 ≥ 44px 高；主按钮始终在屏幕下半部分（单手可达）

**深色模式**：`[data-theme="dark"]` 与 `[data-style="…"]` 正交组合，各自覆盖 token，不改组件结构。深色不是浅色反相：卡片底色比背景亮一档，状态色换成同一色相的高亮版（如 `--ok` 从 `#00B583` 提到 `#2BD9A8`）。

## 6. 状态设计（都要实现）

| 状态 | 呈现 |
| --- | --- |
| 计划未开始 | 顶部提示条"距开跑还有 N 天（2026-10-19），可以先填基线" |
| 今日全部完成 | 环形 100% + "今日打卡完成" + 连续天数 |
| 连续断卡 2 天 | 橙色警示条："已经断 2 天，今天恢复就算赢，别补课、别加量" |
| 空数据 | 趋势页显示"还没有记录，完成第一次打卡后出现数据" |
| 导入失败 | 明确报错原因，不静默失败 |
| 离线 | 灰色信息条，不阻塞操作 |
| 数据缺失 | 指标显示"—"而不是 0（0 会误导） |

## 7. 可访问性

- 状态不只用颜色区分：完成打勾、MVB 用 `~`、跳过用灰底 + 文字，色盲也能分辨。
- 正文对比度 ≥ 4.5:1（`#1B1D21` on `#FFF`）；辅助文字不用于关键信息。
- 支持系统字号放大：布局用 flex 与换行，不写死高度。
- 所有按钮是原生 `<button>`，可键盘聚焦。

## 8. 实现顺序（对齐计划里的 M1–M3）

| 阶段 | 前端范围 |
| --- | --- |
| **M1（现在）** | 今日页 A 方案 + 七天条带补卡 + 底部面板 + 计划页 + 我的页 + 空/未开始状态 |
| **M2** | 趋势页（折线 + 热力格）、指标录入、周复盘表单、深色模式落地 |

## 9. 已确认的决策

1. **今日页用 A 卡片式**（已实现）：任务名 + 说明 + 两个按钮，一眼看清做什么、为什么。
2. **四个 tab 不变**：复盘留在今日页——一周只用一次，不该占主航道的位子。
3. **深色模式进 M1**（已实现）：浅色 / 深色 / 跟随系统三选。

## 10. 风格系统（活力）

"整体偏活力"落到三套可切换的风格包上（`design/themes.css`），而不是只改一个主色：

| 风格 | 主渐变 | 气质 | 建议场景 |
| --- | --- | --- | --- |
| **活力 energy**（默认） | `#6C4CF1 → #1E9BE5` | 靛蓝到亮蓝，薄荷绿收尾 | 通用，浅色深色都稳 |
| **运动 sport** | `#FF4D2D → #E8388C` | 珊瑚到洋红，最冲 | 想被推动一下的时候 |
| **霓虹 neon** | `#00A97A → #0077FF` | 薄荷到电蓝，深色带辉光 | 晚上用，深色模式最好看 |

规则：

- **渐变只用在两处**：大面积色块（顶栏、主按钮、选中胶囊、完成度环）；绝不用在正文或描边上——文字一律用纯色 `--brand` 保证可读。
- 每套风格都有浅色与深色两版取值，`data-style` 与 `data-theme` 正交组合。
- 三套渐变两端都刻意压深，确保白字可读（这是换肤最容易翻车的地方）。
- 活力的其余来源：18px 大圆角、彩色辉光阴影、更粗的标题字重、选中项的渐变胶囊、完成时进度环的辉光。
- 预览：`index.html?style=neon&theme=dark`（只影响当前页面，不写入设置）。
- 切换入口：应用「我的 → 外观」。
